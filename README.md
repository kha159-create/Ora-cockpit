# Ora Cockpit — دليل النظام والميزات

تطبيق ويب لإدارة وتحليل أداء المبيعات والمعارض والموظفين (لوحة **Orange / ORA**). يعرض بيانات مجمّعة من مصادر الإدارة، مع فلاتر زمنية وجغرافية، وتصدير تقارير **PDF** و**Excel**، وخرائط وتقسيمات تارجت متقدمة.

---

## 1. التقنيات (Tech Stack)

| الطبقة | التقنية |
|--------|---------|
| الواجهة | React 18، TypeScript، Vite |
| التوجيه | React Router v6 |
| الرسوم والخرائط | Recharts، Leaflet / react-leaflet |
| الجداول والتصدير | SheetJS (`xlsx`) |
| التقارير PDF | jsPDF + jspdf-autotable (خط Amiri للعربية) |
| البناء | `npm run build` → مجلد `dist` |

---

## 2. الدخول والصلاحيات

- **تسجيل الدخول** (`/login`): شاشة ORANGE DASHBOARD للمصادقة؛ بدون جلسة يُوجَّه المستخدم للّوجين.
- **الأدوار (أمثلة)**:
  - **Admin / Auditor**: رؤية أوسع، فلاتر مديري مناطق، وصول لتقارير شاملة.
  - **BranchManager**: إخفاء عنصر التقارير من القائمة الجانبية.
  - **مدير فرع / مستخدم عادي**: غالباً يُقيَّد عرض الفروع حسب المستخدم.
- عنصر **تحديد الأهداف** (`/targets`) يظهر لـ **Admin** أو للمستخدم باسم **Sales Manager** فقط.

| # | المسار | الاسم في القائمة |
|---|--------|------------------|
| 1 | `/` | لوحة التحكم |
| 2 | `/stores` | المعارض |
| 3 | `/customer-value` | ق.م والمحاكاة |
| 4 | `/comparison` | المقارنات |

| 6 | `/target-split` | تقسيمة التارجت |

| 12 | `/targets` | تحديد الأهداف (مشروط) |

**ميزات عامة في الشريط الجانبي:**

- **بحث عالمي** (Ctrl+K / Cmd+K): استعلام سريع عن منتجات وربطها بمخزون الفروع.
- **استعلام منتجات (Product Inquiry)**: نافذة لتحليل حركة المنتج والمخزون عبر الفروع.
- **مبيعات مباشرة (Live Sales)**: نافذة لمتابعة المبيعات اللحظية حيث يُفعّل ذلك في الإعداد.
- **Comparison Calendar**: سياق تقويمي مشترك (`ComparisonCalendarProvider`) لربط عدة صفحات بنفس منطق «المقارنة بالفترة السابقة» (موسم، سنة سابقة، إلخ).

## 4. الصفحات — رقمياً وميزاتها

### 1) لوحة التحكم — `/`

- **مؤشرات KPI**، مخططات مبيعات/زوار/تارجت، **خريطة الفروع**، ترتيب المعاريض، أكثر المنتجات مبيعاً.
- **أوضاع زمنية**: اليوم، أمس، من بداية الشهر (MTD)، شهر كامل، نطاق مخصص.
- **فلاتر**: مدير منطقة، فرع، مدينة، نوع منشأة (معرض / أونلاين)، وسنة/شهر عند الحاجة.
- **آذار 2026**: دعم مراحل/فترات خاصة (مثل فترتي MTD داخل الشهر) متوافقة مع منطق التارجت في بقية النظام.
- **تقويم المقارنة**: تبديل يعرض المقارنة مع فترة مرجعية (موسم سابق، إلخ) حيث يُطبَّق.
- **تقارير PDF**: تقارير معارض/موظفين يومية أو مجمّعة عبر نوافذ منبثقة.
- **Drill-down**: النقر على يوم في المخطط لفتح تفاصيل يومية.

**قوة العمل:** لوحة مركزية تربط الأهداف، المبيعات، الجغرافيا، والتصدير — مع توحيد منطق التاريخ والمقارنة عبر `ComparisonCalendarContext` و`march2026Targets`.

---

### 2) المعارض — `/stores`

- جدول معارض مع **ترتيب أعمدة**، مبيعات، أهداف، تحقيق، نمو، زوار، **قيمة عميل**، تحويل، ومطلوب يومي.
- **بطاقة تفصيلية** لكل فرع: مؤشرات إضافية، مقارنات، وأحياناً ربط مع أهداف/فترات.
- نفس فكرة **فلترة المدير/المدينة/النوع** وتقويم المقارنة حيث ينطبق.
- دعم **أهداف مارس 2026** ومراحل متعددة للعرض.

**قوة العمل:** صفحة ثقيلة الاستخدام لمراقبة أداء كل فرع بدقة ولحظة بلحظة نسبياً.

---

### 3) قيمة العميل والمحاكاة — `/customer-value`

- صفحة مخصصة لتحليل **قيمة العميل (Customer Value)** والسيناريوهات.
- مكوّنات: **CustomerValueInsights**، **CustomerValueSimulationTable**، ترتيب معارض، خرائط بيانات فروع.
- فلاتر زمنية وإدارية مشابهة للوحة التحكم؛ تتبع **Comparison Calendar** للمقارنات.

**قوة العمل:** فصل تحليل «قيمة العميل» عن باقي اللوحة مع جداول محاكاة قابلة للتوسع.

---

### 4) المقارنات — `/comparison`

- مقارنة مؤشرات بين فترات (اليوم، أمس، MTD، شهر قياسي، مخصص، **مواسم**).
- رسوم بيانية وتفاصيل قابلة للتصفية؛ **DrillDownModal** للتعمق بالتاريخ.
- تصدير **Excel** لبيانات المقارنة حيث يتوفر.

**قوة العمل:** طبقة مخصصة للتحليل التاريخي والموسمي وليس فقط «الشهر الحالي».

---

### 5) الموظفين — `/employees`

- أداء الموظفين حسب الفروع والفترات: مبيعات، فواتير، قطع، تحقيق تارجت، حصة الفرع، إلخ.
- فلاتر نشاط (نشط/غير نشط) وتفاصيل تفصيلية لكل موظف.
- تكامل مع **أهداف الموظف** و**مارس 2026** عند تفعيل التارجت.

**قوة العمل:** ربط بيانات الحركة اليومية للموظف مع أهداف شهرية ومرحلية.

---

### 6) تقسيمة التارجت — `/target-split`

صفحة متخصصة لمقارنة **تارجت الشهر** مع الأداء ضمن **فترات ذكية** داخل الشهر:

- **تقسيم زمني**: يومي، أو **نوافذ 10 أيام**، أو **15 يوماً** — مع **ترحيل الفائض/العجز** بين النوافذ (سلسلة نوافذ).
- لكل **معرض**: ملخص الشهر، ثم جدول فترات (تارجت الفترة بعد الترحيل، مبيعات، تحقيق، معدل فاتورة، تحويل، متبقي، مطلوب لإغلاق الشهر).
- **موظفو الفرع**: لكل موظف — **تارجت الشهر** و**تحقيق الشهر** بجانب الاسم في رأس البطاقة؛ جدول فترات بـ **تحقيق الفترة** (وليس خلطه مع الشهر في عمود التحقيق).
- **قيمة العميل**: تُعرض **للمعرض/الفرع** فقط (واجهة، Excel، PDF لصفحة المعرض). **لا** تُعرض لصفوف **الموظفين** في التقسيمة.
- **تصدير Excel**: ورقة لكل فرع مع أقسام المعرض والموظفين.
- **تصدير PDF**: صفحة معرض (مع **قيمة عميل** للفرع) ثم صفحة موظفين — صف رمادي لكل موظف يضم: الاسم، **تارجت الشهر**، **تحقيق الشهر**؛ صفوف الفترات تعرض **نسبة تحقيق الفترة**؛ **باقي أيام** = **0** بعد انتهاء نافذة الفترة؛ جدول الموظفين **بدون** عمود قيمة عميل.

**قوة العمل:** هذا القسم يمثل أعمق عمل «تحليل أهداف» داخل المشروع: فترات، ترحيل، موظفون، PDF/Excel متسقة، ومنطق زمني دقيق للفترات المنتهية.

---

### 7) العمولات — `/commissions`

- إدارة وعرض **العمولات** المرتبطة بالأداء والفروع/الموظفين (حسب بيانات المصدر).
- واجهة منظمة مع عناوين وتصفية.

---

### 8) المبيعات بالساعة — `/hourly`

- تحليل توزيع المبيعات **حسب الساعة** ضمن الفترة المختارة.
- مفيد لضبط التوظيف والعروض وساعات الذروة.

---

### 9) المنتجات — `/products`

- استكشاف كتالوج المنتجات، المخزون، الحركة، التصنيفات، وربط مع فروع متعددة.
- نوافذ استعلام وتفاصيل عميقة (كميات، فروع، تاريخ).

---

### 10) قائمة العروض — `/offers`

- **تحليل العروض**: أداء العروض، ربطها بالمبيعات، ومؤشرات ملخصة.

---

### 11) التقارير — `/reports`

- مركز **Ora Cockpit** للتقارير المجمّعة: معارض وموظفين، فلاتر زمنية وإدارية.
- **تصدير Excel** و**PDF** مع معاينة واختيار نطاقات؛ تقارير موظفين مع تصفية نشاط.
- ربط مع **تارجت الموظف** ونوافذ اختيار أهداف.

**ملاحظة:** مخفية عن **BranchManager** في القائمة.

---

### 12) تحديد الأهداف — `/targets`

- **تحديد التارجت الشهري** للفروع/السلاسل الزمنية المعتمدة في النظام.
- متاحة فقط لصلاحيات محددة (انظر قسم الصلاحيات).

## 6. الخدمات المشتركة (Backend أمامي)

- **`loadManagementData` / `loadEmployeesData` / `loadProductAnalysisData`**: تحميل الحزم الأساسية للوحة.
- **`pdfService`**: توليد تقارير المعاريض، الموظفين، المنتجات، و**تقسيمة التارجت** بصيغة علامة ORA.
- **`march2026Targets`**: دوال تجميع أهداف الإدارة والموظفين لشهر/فترات محددة (يشمل منطق آذار 2026).
- **`targetSplitPeriods`**: بناء «السلال» الزمنية والمراحل للتقسيمة.
- **`seasons` / `ComparisonCalendarContext`**: مواسم مقارنة وتواريخ هجرية/ميلادية للعرض.

---

## 7) نقاط قوة ما تم إنجازه في المشروع (ملخص)

1. **لوحة موحّدة** تربط KPI، خرائط، تارجت، ومقارنات زمنية.
2. **تقسيمة التارجت** كمنتج كامل: فترات 10/15 يوماً مع ترحيل، موظفون لكل فرع، رؤى ضعف/قوة، وتصدير PDF/Excel متسق مع المنطق.
3. **صفحة قيمة العميل والمحاكاة** منفصلة لاتخاذ قرارات تسعير/زوار دون إغراق لوحة التحكم.
4. **تقارير وتصدير** احترافي (عربي في PDF، Excel للتحليل).
5. **صلاحيات وواجهات** تتكيف مع مدير فرع مقابل إدارة مركزية.
6. **تكامل تقويم المقارنة** عبر عدة صفحات لضمان أن «نفس الفترة المرجعية» تُفهم بنفس الطريقة في كل مكان.
