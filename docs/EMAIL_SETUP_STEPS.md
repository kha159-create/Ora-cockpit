# إعداد إرسال التقارير بالإيميل — خطوة بخطوة

## ما المطلوب منك (بدون كود)

### الخطوة 1: اختيار مزود الإيميل

اختر **واحدة** من الخيارات التالية:

| الخيار | الموقع | ملاحظة |
|--------|--------|--------|
| **SendGrid** | https://sendgrid.com | مجاني حتى حد معين (مثلاً 100 إيميل/يوم) |
| **Resend** | https://resend.com | سهل، يدعم Node.js جيداً |
| **SMTP عادي** | (Gmail / Outlook / سيرفر الشركة) | تحتاج تفعيل "App Password" أو بيانات SMTP |

---

### الخطوة 2: إنشاء حساب ومفتاح API (إن كان SendGrid أو Resend)

#### إذا اخترت SendGrid:
1. سجّل دخول في https://sendgrid.com
2. من القائمة: **Settings** → **API Keys** → **Create API Key**
3. اختر اسم (مثل `Ora-cockpit-daily-report`) وصلاحية **Full Access** أو **Restricted** (مع إرسال Mail فقط)
4. انسخ المفتاح **مرة واحدة** (لن يظهر مرة ثانية) واحفظه

#### إذا اخترت Resend:
1. سجّل دخول في https://resend.com
2. من **API Keys** أنشئ مفتاحاً جديداً
3. انسخ المفتاح واحفظه

---

### الخطوة 3: إضافة المتغيرات في Vercel

1. ادخل إلى مشروعك على https://vercel.com
2. افتح المشروع **Ora-cockpit** (أو اسمه عندك)
3. اذهب إلى **Settings** → **Environment Variables**
4. أضف المتغيرات التالية:

| اسم المتغير | القيمة | ملاحظة |
|-------------|--------|--------|
| `REPORT_EMAIL_TO` | `email1@example.com,email2@example.com` | عناوين الإيميل التي تستلم التقارير (مفصولة بفاصلة) |
| `CRON_SECRET` أو `REPORT_CRON_SECRET` | كلمة سر طويلة عشوائية (مثلاً 32 حرف) | لتفادي أن يفعّل أحد الرابط بدون صلاحية |
| **SendGrid:** `SENDGRID_API_KEY` | المفتاح الذي نسخته من SendGrid | |
| **أو Resend:** `RESEND_API_KEY` | المفتاح من Resend | |
| **أو SMTP:** `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | بيانات السيرفر والبريد | |

5. احفظ (Save) ثم اعمل **Redeploy** للمشروع حتى تُطبَّق المتغيرات.

---

### الخطوة 4: تفعيل الجدولة (Cron) على Vercel

1. في نفس المشروع على Vercel، تأكد أن ملف `vercel.json` يحتوي على:

```json
"crons": [
  {
    "path": "/api/daily-report-email",
    "schedule": "0 9 * * *"
  }
]
```

- `0 9 * * *` = كل يوم الساعة 09:00 UTC (تقريباً 12:00 ظهراً بتوقيت السعودية).
- إذا لم يكن موجوداً، يُضاف ثم يُرفع التعديل (commit + push) ويُعاد النشر.

2. **ملاحظة:** خطة Vercel المجانية قد لا تدعم Cron؛ إن لم يعمل، استخدم الخطوة 5.

---

### الخطوة 5 (بديل): استخدام موقع مجاني لجدولة الطلب

إذا Cron على Vercel غير متاح:

1. ادخل إلى https://cron-job.org (أو أي خدمة مثل EasyCron)
2. أنشئ مهمة جديدة (Cron Job)
3. **الرابط:**  
   `https://ora-cockpit.vercel.app/api/daily-report-email?secret=المفتاح_الذي_وضعته_في_CRON_SECRET`
4. **التوقيت:** يومياً الساعة 12:00 (اختر توقيت السعودية إن وُجد)
5. احفظ المهمة

بهذا يتم استدعاء الـ API كل يوم في الموعد المحدد.

---

### الخطوة 6: إكمال الكود (يحتاج مطور)

حالياً الـ API `api/daily-report-email.ts` يقوم بـ:

- التحقق من المفتاح
- جلب البيانات من المصدر
- حساب بيانات التقرير اليومي

ما **لم يُنفَّذ بعد** (يحتاج إضافته في المشروع):

1. **توليد ملف PDF على السيرفر**  
   باستخدام مكتبة تعمل في Node (مثل `jspdf` أو `pdf-lib`) بنفس شكل التقرير اليومي.

2. **إرسال الإيميل مع المرفق**  
   باستخدام:
   - SendGrid: استدعاء واجهة SendGrid مع المرفق (PDF)
   - أو Resend: نفس الفكرة
   - أو Nodemailer إذا استخدمت SMTP

بعد تنفيذ هاتين النقطتين في الكود، التقارير ستُرسل تلقائياً حسب الجدولة التي اخترتها.

---

## ملخص سريع (ما الذي تفعله أنت بدون مطور)

1. إنشاء حساب SendGrid أو Resend (أو تجهيز SMTP).
2. إنشاء مفتاح API ونسخه.
3. في Vercel: إضافة `REPORT_EMAIL_TO` و `CRON_SECRET` و `SENDGRID_API_KEY` (أو Resend/SMTP).
4. إما تفعيل Cron في `vercel.json` وإعادة النشر، أو استخدام cron-job.org مع الرابط + `?secret=...`.
5. الباقي (توليد PDF وإرسال الإيميل في الكود) يحتاج مطور لإكماله في `api/daily-report-email.ts`.
