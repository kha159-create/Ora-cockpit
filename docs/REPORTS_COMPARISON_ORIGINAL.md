# مقارنة التقارير مع الريبو الأصلي (orange-dashboard)

تم إعادة كتابة هيكل صفحة التقارير ليطابق الريبو الأصلي: **نوع التقرير** (الفترة + الفلاتر)، **التقرير اليومي**، **تفاصيل الفروع (Detailed Report)** مع PDF و Excel، **ملخص عام والتقرير الشهري**، **تصدير Excel** (نافذة مع اختيار نوع التقرير: مبيعات المعارض / مبيعات الموظفين)، **تقارير الموظفين** (أداء الموظفين، تقرير أمس، Excel، قالب تارجت، رابط صفحة أداء الموظفين).

## التقارير في الريبو الأصلي (حسب الصفحة)

### 1. الصفحة الرئيسية (index.html)
| التقرير | الوصف | المطابق عندنا |
|---------|--------|----------------|
| **PDF** | اختيار فرع (الكل أو فرع واحد) + خيار "إنشاء صفحة تفصيلية لكل فرع" → ملخص عام و/أو صفحة يومية لكل فرع | ✅ تقرير المعارض + زر "PDF ملخص لكل فرع" + "طباعة PDF" (جدول واحد) |
| **Excel** | تصدير مبيعات المعارض (فترة + فلاتر) | ✅ بيانات المعارض Excel |
| **Excel** | تصدير مبيعات الموظفين (لـ Sales Manager / Admin) | ✅ بيانات الموظفين Excel |
| **تقرير يومي** | تقرير الأمس مقارنةً بنفس اليوم العام الماضي (جدول المعارض) | ✅ التقرير اليومي (من الصفحة الرئيسية + من التقارير) |
| **تصدير تفصيلي** | تصدير الجدول الحالي (جدول الفروع) إلى Excel/PDF | ✅ معاينة التقرير ثم طباعة PDF أو استخدام نفس الفلاتر في تقارير أخرى |

### 2. صفحة الموظفين (employees.html)
| التقرير | الوصف | المطابق عندنا |
|---------|--------|----------------|
| **تصدير Excel** | تقرير يومي مفصل / بيانات الموظفين لفترة | ✅ بيانات الموظفين Excel (صفحة التقارير) |
| **PDF** | اختيار موظفين ثم إنشاء تقرير (أمس + MTD، صفحة لكل فرع) | ✅ أداء الموظفين + تقرير أمس (PDF) + قالب تارجت |

### 3. تحليل العروض (offers_analysis.html)
| التقرير | الوصف | المطابق عندنا |
|---------|--------|----------------|
| **Excel** | تصدير تحليل العروض (جدول العروض + أكثر المنتجات مبيعاً) | ✅ صفحة تحليل العروض → تصدير Excel |
| **PDF** | تقرير تحليل العروض (ملخص + جدول) | ✅ صفحة تحليل العروض → تصدير PDF |

### 4. تحليل المنتجات (product_analysis.html + product_pdf_export.js)
| التقرير | الوصف | المطابق عندنا |
|---------|--------|----------------|
| **Excel** | تصدير تحليل المنتجات (قائمة المنتجات بالفئة والكمية والمبيعات) | ✅ صفحة تحليل المنتجات → تصدير Excel |
| **PDF** | تقرير تحليل المنتجات (ملخص جدول) | ✅ صفحة تحليل المنتجات → تصدير PDF |

### 5. تفاصيل الفرع (branch_details.html)
| التقرير | الوصف | المطابق عندنا |
|---------|--------|----------------|

## ما تم تنفيذه في Ora-cockpit (صفحة التقارير)

1. **تقرير المعارض**
   - عنوان النافذة: كان يظهر "أداء الموظفين" → تم تصحيحه إلى "تقرير المعارض".
   - خيار **PDF ملخص لكل فرع**: زر إضافي يعطي PDF بصفحة ملخص عام ثم صفحة لكل فرع (نفس آلية الريبو الأصلي).
   - **طباعة PDF**: جدول واحد (أمس أو الفترة) مقارنة العام الماضي.

2. **Excel مبيعات المعارض**
   - إضافة أعمدة: **الهدف**، **نسبة التحقيق**، وتسميات مطابقة للأصلي (المبيعات، مبيعات السنة السابقة، زوار السنة السابقة).

3. **Excel مبيعات الموظفين**
   - إضافة أعمدة: **مبيعات السنة السابقة**، **الهدف (الشهري)**، والرقم الوظيفي بدون الشرطة عند الحاجة.

4. **الفلاتر**
   - تطبيق مدير المنطقة، المدينة، نوع المعرض، الفرع على كل التقارير وعلى قائمة الفروع.

5. **النشط في قالب التارجت**
   - الموظف يعتبر نشطاً إذا (أيام مبيعات ≥ 3 وحصة من الفرع ≥ 1%).

## جمع ودمج التقارير: هل جمعنا كل ما في الأصلي؟

نعم. تم جمع **جميع** التقارير الموجودة في الريبو الأصلي (من كل الصفحات) ودمجها في تطبيقنا كما يلي:

| # | التقرير في الريبو الأصلي | مكانه عندنا (صفحة التقارير أو غيرها) |
|---|---------------------------|----------------------------------------|
| 1 | PDF المعارض (الكل أو فرع + صفحة تفصيلية لكل فرع) | صفحة التقارير → تفاصيل الفروع → PDF، ثم من المعاينة: طباعة PDF أو PDF ملخص لكل فرع |
| 2 | Excel مبيعات المعارض | صفحة التقارير → تصدير Excel → مبيعات المعارض (Store Sales) |
| 3 | Excel مبيعات الموظفين | صفحة التقارير → تصدير Excel → مبيعات الموظفين (Employee Sales) |
| 4 | التقرير اليومي (أمس vs العام الماضي) | صفحة التقارير → التقرير اليومي → عرض التقرير اليومي |
| 5 | تفاصيل الفروع (جدول + PDF + Excel) | صفحة التقارير → تفاصيل الفروع (Detailed Report) → PDF و Excel |
| 6 | ملخص عام (Global Summary) | صفحة التقارير → ملخص عام والتقرير الشهري → ملخص عام |
| 7 | التقرير الشهري | صفحة التقارير → ملخص عام والتقرير الشهري → التقرير الشهري |
| 8 | PDF أداء الموظفين (اختيار موظفين، أمس + MTD، صفحة لكل فرع) | صفحة التقارير → تقارير الموظفين → أداء الموظفين (عرض + PDF)؛ وتقرير أمس (موظفين) |
| 9 | قالب تارجت الشهر القادم | صفحة التقارير → تقارير الموظفين → قالب تارجت الشهر القادم |
| 10 | تقرير يومي مفصل (موظفين) / بيانات الموظفين Excel | صفحة التقارير → تصدير Excel (موظفين) أو تقارير الموظفين → تصدير Excel (موظفين) |
| 11 | تصدير PDF + Excel تحليل المنتجات (من صفحة المنتجات) | ✅ صفحة تحليل المنتجات: أزرار «تصدير Excel» و «تصدير PDF» في شريط الفلاتر |
| 12 | تصدير PDF تحليل العروض (من صفحة العروض) | ✅ صفحة تحليل العروض: زر «تصدير PDF» بجانب «تصدير Excel» |
| 13 | تفاصيل فرع واحد (من branch_details) | نفس تقرير المعارض مع فلتر فرع واحد + خيار PDF ملخص لكل فرع |

**الخلاصة:** كل التقارير الموجودة في الريبو الأصلي (الصفحة الرئيسية، صفحة الموظفين، تصدير Excel/PDF، التقرير اليومي، تفاصيل الفروع، التارجت، **تحليل العروض**، **تحليل المنتجات**) **مجمعة وموجودة عندنا** إما في صفحة التقارير أو في الصفحة المناظرة (المنتجات، العروض). التصميم يبقى تصميمنا؛ المهام والتقارير مطابقة للأصلي.

## خلاصة

- تقارير المعارض (PDF جدول واحد + PDF ملخص لكل فرع)، والملخص العام، والتقرير الشهري، وأداء الموظفين، وبيانات المعارض/الموظفين Excel، وقالب التارجت **موجودة ومحاذاة مع آلية الريبو الأصلي**.
- **تحليل العروض:** تصدير Excel و PDF من نفس الصفحة (مطابق للأصلي).
- **تحليل المنتجات:** تصدير Excel و PDF من نفس الصفحة (مطابق للأصلي).
